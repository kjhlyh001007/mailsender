# 메일 대량 발송 프로그램 (메일플러그용)

엑셀 명단을 올리면 이름(또는 다른 컬럼)을 자동으로 바꿔 넣어서, 여러 명에게 한 번에
개인화된 메일을 보내는 프로그램입니다. 사진(본문 삽입)과 첨부파일을 모두 지원하고,
자주 쓰는 제목/본문 양식은 저장해뒀다가 다음에 바로 불러올 수 있습니다.

이 프로그램은 **본인 컴퓨터에서 직접 실행**합니다. 이메일 비밀번호가 외부로
전송되지 않고, 여러분의 컴퓨터에서 메일플러그 서버로 바로 연결됩니다.

## 1. 최초 1회 준비 - 메일플러그 설정

1. https://login.mailplug.com 에 로그인합니다.
2. 환경설정(계정 설정)에서 **"IMAP/SMTP 사용"** 또는 **"POP3/SMTP 사용"** 항목을
   **'사용'**으로 변경합니다.
3. 로그인 보안 설정 메뉴에서 **앱 비밀번호(App Password)**를 발급받습니다.
   (평소 로그인 비밀번호가 아니라 외부 프로그램 전용 비밀번호입니다.)
4. 회사에서 발급한 그룹웨어/기업메일 계정이라면, 회사 관리자에게 외부 SMTP 발송이
   허용되는지 먼저 확인해주세요. (2025년 4월 1일 이후 개통 계정은 일부 제한이 있을
   수 있습니다.)

문의: 메일플러그 고객센터 1544-9140

## 2. 프로그램 설치 / 실행 — 두 가지 방법

### 방법 A. 파이썬으로 직접 실행 (파이썬 설치 필요)

컴퓨터에 파이썬(Python 3.9 이상)이 설치되어 있어야 합니다.
[python.org](https://www.python.org/downloads/)에서 설치할 수 있습니다.

이 폴더(`mail_merge_app`)를 통째로 다운로드한 뒤, 터미널(명령 프롬프트)에서 이
폴더로 이동하여 아래 명령을 실행하세요.

```bash
pip install -r requirements.txt
streamlit run app.py
```

실행하면 자동으로 웹브라우저가 열리고 프로그램 화면이 나타납니다.

### 방법 B. 파이썬 설치 없이, 더블클릭용 실행 파일(.exe/.app) 만들기

이 폴더에는 GitHub의 무료 빌드 서버(GitHub Actions)가 자동으로 윈도우용 `.exe`와
맥용 `.app`을 만들어주는 설정이 이미 들어있습니다(`.github/workflows/build.yml`).
빌드는 GitHub의 서버에서 일어나기 때문에, **내 컴퓨터에는 파이썬을 설치할 필요가
없습니다.** 순서는 이렇습니다.

1. https://github.com 에서 무료 계정을 만듭니다 (이미 있으면 생략).
2. 오른쪽 위 **+ → New repository**로 새 저장소를 하나 만듭니다 (이름은 아무거나,
   Public/Private 상관없음).
3. 만든 저장소 화면에서 **Add file → Upload files**를 누르고, `mail_merge_app`
   폴더 안의 파일/폴더를 전부(`.github`, `.streamlit` 처럼 점(.)으로 시작하는
   폴더 포함) 끌어다 놓고 **Commit changes**를 누릅니다. (터미널이나 git 명령어
   없이, 웹 화면 드래그앤드롭만으로 됩니다.)
   - ⚠️ **맥에서는** `.github`, `.streamlit` 폴더가 Finder에 기본적으로 안 보일 수
     있습니다. Finder에서 `Cmd + Shift + .` (마침표)를 눌러 숨김 파일을 보이게
     한 다음 끌어다 놓으세요. 이 두 폴더가 빠지면 자동 빌드가 동작하지 않습니다.
4. 저장소 상단 메뉴의 **Actions** 탭으로 들어가면 "실행 파일(exe/app) 빌드"라는
   작업이 자동으로 시작되어 있을 거예요(없으면 왼쪽 목록에서 클릭 후
   **Run workflow** 버튼). 5~10분 정도 걸립니다.
5. 빌드가 끝나면(초록 체크 표시) 그 작업 화면 맨 아래 **Artifacts** 항목에
   `MailMergeApp-Windows`(윈도우용), `MailMergeApp-Mac`(맥용) 두 개가 생깁니다.
   본인 컴퓨터에 맞는 걸 눌러 다운로드한 뒤 압축을 풀면 실행 파일이 나옵니다.
6. 더블클릭으로 실행합니다.
   - **윈도우**: "Windows의 PC 보호" 경고가 뜰 수 있습니다 → **추가 정보** →
     **실행** 을 누르면 됩니다. (서명되지 않은 개인 프로그램이라 뜨는 정상적인
     경고입니다.)
   - **맥**: "확인되지 않은 개발자" 경고가 뜨면 파일을 **control+클릭(우클릭) →
     열기**로 실행하거나, 시스템 설정 → 개인정보 보호 및 보안에서 허용해주세요.

이 방식은 화면이 브라우저 탭이 아니라 독립된 프로그램 창으로 뜹니다. 처음 빌드할
때 오류가 날 수도 있는데(Streamlit을 실행 파일로 묶는 과정 자체가 원래 까다로운
작업이라 그렇습니다), Actions 탭의 빨간 X 표시를 눌러 나오는 로그 내용을 알려주시면
원인을 봐드릴 수 있습니다.

제목/본문 양식과 계정 정보는 이 경우 실행 파일이 있는 폴더가 아니라, 아래 위치에
자동으로 저장됩니다.

- 윈도우: `%APPDATA%\MailMergeApp`
- 맥: `~/Library/Application Support/MailMergeApp`

## 3. 사용 순서

1. **왼쪽 사이드바**에 보내는 메일 주소, 로그인 아이디, 앱 비밀번호를 입력합니다.
2. **엑셀 명단 업로드** - 받는 사람 명단이 담긴 .xlsx 파일을 올립니다. 이름 컬럼과
   이메일 컬럼을 지정하고, 보낼 대상만 체크박스로 선택합니다(전체 선택도 가능).
3. **제목/본문 작성** - 본문에 `{{이름}}` 처럼 엑셀 컬럼명을 이중 중괄호로 감싸면,
   받는 사람마다 자동으로 그 사람의 값으로 바뀝니다. 이름뿐 아니라 엑셀에 있는
   어떤 컬럼이든 (`{{회사}}`, `{{직급}}` 등) 자리표시자로 쓸 수 있습니다.
   작성한 제목/본문은 이름을 붙여 저장해두면 다음에 실행할 때도 그대로 불러와
   재사용할 수 있습니다.
4. **사진/첨부파일** - 본문 안에 바로 보이는 사진은 "본문 삽입용 사진"에 올리고,
   본문에 `{{사진1}}`, `{{사진2}}`처럼 위치를 지정하면 그 자리에 삽입됩니다
   (지정하지 않으면 본문 맨 위에 자동으로 붙습니다). 별도 파일로만 보낼 문서는
   "첨부파일"에 올립니다.
5. **미리보기**에서 받는 사람 한 명을 골라 실제로 어떻게 보일지 확인합니다.
6. **테스트 발송(나에게만 1통)** 을 먼저 눌러 정상적으로 도착하는지 확인한 뒤,
   문제가 없으면 **전체 발송**을 누릅니다. 발송 간 간격(기본 2초)을 두어 스팸으로
   차단될 위험을 줄입니다. 발송이 끝나면 성공/실패 결과를 표와 CSV로 받아볼 수
   있습니다.

## 4. 참고 사항 및 주의점

- 비밀번호(앱 비밀번호)는 프로그램에 저장되지 않으며, 실행할 때마다 다시
  입력해야 합니다. 이메일 주소/아이디만 원하면 저장해둘 수 있습니다
  (`smtp_config.json` 파일에 평문으로 저장되니, 공용 컴퓨터에서는 체크하지 마세요).
- 저장한 제목/본문 양식은 `templates/templates.json` 파일에 저장됩니다. 이 파일을
  다른 컴퓨터로 옮기면 양식도 그대로 옮겨집니다.
- 짧은 시간에 아주 많은 인원(수백~수천 명)에게 보내면 메일플러그 또는 상대방
  메일 서버가 스팸으로 판단해 차단할 수 있습니다. 대량/정기 발송이 잦다면
  SendGrid, Amazon SES 같은 전용 이메일 발송 서비스 사용을 검토하는 것이
  안전합니다.
- 회사 보안 정책에 따라 메일플러그 관리자가 외부 SMTP 접속 자체를 막아둔 경우,
  개인 계정 설정만으로는 해결되지 않을 수 있습니다. 이 경우 회사 IT/메일
  담당자에게 문의해주세요.
- 방법 B(exe/app)로 만든 실행 파일은 파이썬과 필요한 라이브러리를 통째로
  담고 있어서 용량이 100~250MB 정도로 큽니다. 실행할 때 창이 뜨기까지 몇 초
  걸릴 수 있는데, 정상입니다.
